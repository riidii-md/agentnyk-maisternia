# Engineering Policy

- Discover repository rules before assuming conventions.
- Prefer existing repository patterns and tools.
- Separate facts, assumptions, inferences, and unknowns.
- Define observable acceptance criteria before implementation.
- Work in small, restartable tasks.
- Run deterministic verification before agent review.
- Use independent contract and code review.
- Preserve complete logs outside concise chat summaries.
- Keep provider aliases aligned with canonical phase definitions.
- Scale test and review depth with risk and blast radius.
