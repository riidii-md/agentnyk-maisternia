# /work-showcase - Create a Readable Review Document

Produce a standalone Markdown report after substantial analysis, research,
planning, implementation, or review.

Input:

`$ARGUMENTS`

Include when relevant:

- executive summary;
- current status;
- problem and goal;
- findings;
- decision or proposed direction;
- architecture or flow;
- risks and unknowns;
- approvals needed;
- next steps;
- sources and local files.

Use Mermaid only where it materially improves understanding. Render through the
configured readable-output tool. Do not include secrets or raw sensitive logs.
