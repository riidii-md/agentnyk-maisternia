# /machine-cleanup

When this invocation authors or revises document prose, read the installed
`readable-output` skill's `references/document-wording.md` and apply it before finalization.
Before requesting a human response to an actual document, use that skill's
**Document-bound human checkpoints** contract. Ordinary clarification does not
require a document, structural adaptation, or publication.

Use the installed `machine-cleanup` skill with `$ARGUMENTS` and the current
user's storage goal. If the skill or a required reference is unavailable,
report that missing resource and stop the dependent action.

Maisternia installs this command; the interactive harness executes the skill.
Installation and invocation do not approve a cleanup action. Antigravity's
managed prompt tree is compatibility packaging, not verified discovery.
